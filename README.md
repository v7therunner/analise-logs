# Análise e Investigação de Logs

Projeto pessoal prático voltado para a rotina de um analista SOC N1: geração de 
eventos de segurança em ambiente controlado e investigação manual dos logs 
gerados, sem depender de dashboard/SIEM.

## Cenário

Força Bruta via SMB — Ataque simulado a partir de uma VM Kali Linux contra uma VM Windows 10, com 
investigação dos eventos 4625 gerados no Event Viewer.

## Ambiente
- Atacante: Kali Linux
- Alvo: Windows 10 Home
- Ferramenta: CrackMapExec (CME); Event Viewer
